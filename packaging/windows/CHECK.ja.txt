第一部 ── 直したものを確かめる
==============================

1. 言語（前回: 英語にしても日本語が6語残った）
----------------------------------------------

  原因は訳し忘れではなく、**訳したものが読み込み時に凍っていた**ことでした。

  [ ] `T` → 「言語」→ Enter で English に
  [ ] そのまま `,`（並び替え）を開く
      → **Name / Size / Date / Extension**（名前・サイズ・日時・拡張子ではなく）
  [ ] `T` の一覧に **notepad**（メモ帳ではなく）
  [ ] `M` → 「表示 ▸」に **Icons / Classic**（アイコン・クラシックではなく）
  [ ] `T` →「Language」→ Enter で日本語に戻る


2. メニューの動き（前回: スクロールが追随しない・マウスに引っ張られる）
----------------------------------------------------------------------

  [ ] `M` を開き、↓ を押し続ける
      → **選択行がいつも見えている**（下に消えていかない）
  [ ] `M` を開き、**マウスを一覧の真ん中に置いたまま動かさず**に ↑↓
      → **カーソルが素直に動く**（ポインタの行に引き戻されない）
      ※ ここが前回いちばん触りにくかったところです
  [ ] `T` でも同じ（マウス静止のまま ↑↓）
  [ ] マウスを**動かせば**ちゃんとその行に移る（殺してはいません）


3. 見た目（前回: 右の枠線が無い・スクロールバーがダサい）
--------------------------------------------------------

  [ ] ファイルペインの**右端の枠線が4辺ともある**
      → 前回消えていたのは、Windows のスクロールバーが枠の上に乗っていたため
  [ ] スクロールバーが細く、地の色に馴染んでいる（両端の矢印ボタンが無い）
  [ ] 配色を変える（`M` →「テーマ（全体）」）と**スクロールバーの色も変わる**


4. テーマ（前回: ペイン個別テーマが全体テーマで戻らない）
--------------------------------------------------------

  [ ] `M` →「表示 ▸」→「テーマ（このペイン）」で片方だけ着替える
  [ ] そのまま `M` →「テーマ（全体）」で別のテーマを選ぶ
      → **両ペインとも新しいテーマになる**（片方が前の色のまま残らない）
  [ ] 「背景色」で片ペインを着替えたあとも同じ


5. o と O（前回: 未実装に見えた）
--------------------------------

  動いていました。**ヘルプの説明が両方とも逆**でした。

  [ ] 左右を違う場所にしてから、左で `o`
      → **左が右と同じ場所になる**（反対側をここへ）
  [ ] 続けて左で `O`
      → **右が左と同じ場所になる**（このペインを反対側へ）
  [ ] `?` のヘルプで o と O が別々の行になっていて、説明が上と合っている


6. シェル（前回: コマンドプロンプトだった）
-------------------------------------------

  [ ] `J` でシェル → **Windows PowerShell** が出る
      （`PS C:\...>` のプロンプト。`C:\...>` ではなく）
  [ ] `$PSVersionTable` が答える
      ※ init.lua の `cian.set_option("shell", …)` は今も優先されます


7. SSH と SFTP（前回: :ssh がリモートペインを開いた）
----------------------------------------------------

  **ここが今回いちばん大きく変えたところです。** 端末版に合わせました。

  [ ] `Shift+S`（または `:ssh`）→ ホスト一覧
      → 選ぶと **シェルパネルが開いて `ssh user@host` が走る**
        （リモートペインではありません）
  [ ] init.lua にパスワードを書いてあるホストなら、
      **パスワードを訊かれた時点で自動で送られる**
      → 「訊かれたらパスワードを送ります」と下に出ます
  [ ] 鍵で入るホストなら「→ user@host」とだけ出て、あとは ssh 任せ
  [ ] `:sftp` → **init.lua のホスト一覧が出る**
      （前回は user@host の手入力箱に直行していました）
  [ ] その一覧で **F2** を押すと今までどおり手入力にできる
  [ ] `M` →「SSH接続」も上と同じ（シェルで開く）

  ※ ホスト鍵を初めて訊かれたとき（yes/no）は**自分で答えてください**。
    そこにパスワードは送りません。

第二部 ── 直せなかった3件を捕まえる
====================================

**ここが本題です。** 3件とも Mac では再現しませんでした。
再現手順ではなく、**そのとき画面に出た文字**を欲しています。


A. .md が開かない → シェルにも入力できなくなる
----------------------------------------------

  前回の報告:
    「.mdが開かない。別のペインにアクティブを移動して、戻ってくると
      開いたが、もう一回開こうとすると、アクティブペインを変更しても
      ダメだった。というか、この状態でシェルペインに移動しても
      何も入力できないなぁ」

  Mac では開き直せてしまいます。詰まった状態を作れたら:

  [ ] **詰まった状態のまま「:」→ key と打ってから `j` を押す**

      ・`Process code=KeyJ` のような行が出る → キーは届いています
      ・**何も出ない** → 鍵盤がどこかに囚われています
      ・そもそも「:」が効かない → それも情報です。**そう書いてください**

      出た行を**そのまま**送ってください。Esc で止まります。

  あわせて、詰まる直前に何をしていたかを一言:
      ・Ctrl+E（プレビュー切替）を押していた？
      ・比較（`=`）を開いていた？
      ・zip の中にいた？
      ・その .md は大きい？ mermaid が入っている？


B. F10 で3タブ目と2タブ目の両方が閉じた
---------------------------------------

  シェルのタブでもファイルペインのタブでも再現しませんでした（3→2）。

  [ ] 前回と同じ手順をもう一度やって、次の3つを教えてください

      ① そのとき**キーはどちらにありましたか**
         ・シェルパネル（下に PS のプロンプトが見えている）
         ・ファイルペイン（一覧の側）
      ② **確認ダイアログは何回出ましたか**（1回 / 2回）
      ③ ダイアログの文言は
         ・「このタブを閉じます」        ＝ ファイルペインのタブ
         ・「このシェルタブを閉じます（分割ごと）」＝ シェルのタブ
         どちらでしたか。**両方出たならそれが答えです**


C. 初回だけ IME がオフになる
----------------------------

  cian は触っていません ── IME 連携（`:ime`）は既定でオフで、
  オンにしない限り何も呼びません。**Windows は IME の状態を窓ごとに
  持つ**ので、新しく作られた窓が既定（オフ）で始まる、が素直な説明です。

  そして窓は**物理キーを読む**ので、IME がオンのままでも困らないはず。
  そこだけ確かめてください:

  [ ] IME を**オンにしたまま**一覧で `j` `k` `Space` `/`
      → 効く（IME は切り替わらない）
      → **効かないなら、A と同じく「:」→ key で出た行を送ってください**

  これが効いているなら、初回オフは実害なしとして閉じます。
  気になるなら追いますので、言ってください。
