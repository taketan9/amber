cian-gui 実機チェックリスト
===========================

2026-09-01 の回で入ったもの。**上から順に、20 分ほどで一周できます。**

このリストは「直したと言っているもの」と「一度も動かしていないもの」を
分けてあります。◆ が付いているものは **Mac では一度も通せていません**
（SFTP サーバも Windows も手元に無いため）。そこが今回いちばん見てほしい所です。

落ちたときは、その番号と、画面に出た文字をそのまま送ってください。
「効かない」より「N番、こう出た」の方が、こちらで再現できる確率が段違いです。


0. まず版を確かめる
-------------------

  [ ] 窓の中で「:」→ version
      ビルド日時と commit が出ます。**古い exe を掴んでいるのが
      いちばん多い落とし穴**なので、ここが今日の日付でなければ
      それ以降のチェックは意味がありません。


1. 見た目 ── すぐ目に入るもの
-----------------------------

  [ ] 一覧の列見出しが「名前 / サイズ / 日時」
  [ ] git のリポジトリを開くと、行の左に1文字の印が出る
        ● ステージ済み  ✚ 変更あり  ? 未追跡  ‼ 衝突
        ~ その下に変更があるディレクトリ
      → **`~` が出るか**を特に見てください。中に入らずに
        「次はどこか」が分かるのが、この列の値打ちです
  [ ] パンくずの右端に ◂ ▶。押すと履歴を前後する
  [ ] `:view icons` にすると、**OS の本物のアイコン**が出る
      （.xlsx なら Excel の絵、PNG はサムネイル。絵文字ではない）


2. 言語
-------

  [ ] `T` → 「言語」→ Enter で English に変わる
  [ ] そのまま `?`（ヘルプ）が英語で出る
  [ ] メニュー（`M`）も英語
  [ ] `:` を打つ → `C` でコマンド一覧、説明が英語
  [ ] もう一度 `T` →「Language」→ Enter で日本語に戻る
      ※ 覚えません（端末版と同じ）。init.lua の
        `cian.set_option("lang", "en")` が既定になります


3. IME ── **これが今回いちばん見てほしいものです**
--------------------------------------------------

  [ ] 日本語 IME を**オンにしたまま**、一覧で `j` `k` を押す
      → カーソルが上下に動く（IME は切り替わらない）
  [ ] 同じく IME オンのまま `T` → スイッチが開く
  [ ] 同じく IME オンのまま `Space` でマーク、`/` で絞り込み

  仕組み: 窓は変換中でも「どの物理キーか」を教えてもらえます。
  端末版は文字そのものが届かないので、外部ヘルパー（im-select）で
  IME を切るしかありませんでした。**窓版はヘルパー無しで効くはず**です。

  [ ] 効かないときは「:」→ key を打ってから `j` を押してください。
      `Process code=KeyJ` と出れば仕組みは届いています（当たりが別）。
      何も出なければ届いていません。**その出力をそのまま送ってください。**

  ※ 記号（`/` `,` `:`）は意図的に対象外です。物理位置は JIS と US で
    違うので、当てにいくと指の下に別の文字が出ます。


4. エディタと図
---------------

  [ ] `.md` を F3 で開く → **vim のノーマルモードで開く**（既定が変わりました）
      メモ帳流がよければ `T` →「エディタのキー操作」で戻せます
  [ ] mermaid を含む .md で `Ctrl+E` → 組んだ表示 → もう一度 `Ctrl+E`
      → **ソースに戻り、図はフェンスの真下に出たまま**
  [ ] `:mermaid` で図だけの表示、`:mermaid!` でブラウザ
  [ ] 画像を F3 → `+` `−` で拡大縮小、`0` 原寸、`f` 窓に合わせる、
      ドラッグで移動、`E` で外部エディタ


5. 比較
-------

  [ ] 左右で違うファイルを1つずつ選んで `=`
      → **並べた差分エディタが直接開く**（行の一覧ではなく）
  [ ] `L` で一覧に切り替わる
  [ ] 一覧で `e` を押すと文字コードが巡回する（Shift_JIS の2つを
      UTF-8 で読むと全行が「違う」になるのを避けるため）
  [ ] 一覧で `>` → 「上書きします」と訊く → Esc で「やめました」


6. メニューに増えたもの
-----------------------

  [ ] `M` → 「背景色」→ ↑↓ で**ペインの地色がその場で変わる**、Esc で戻る
  [ ] `M` → 「表示 ▸」→「テーマ（このペイン）」→ 片方のペインだけ着替わる
  [ ] `M` → 「開く / 場所 ▸」に
        「開く」「プログラムから開く」◆「エクスプローラーで表示」「プロパティ」
      → **Windows では「プログラムから開く」が出るはず**（Mac には無い行です）
  [ ] `M` → 「テーマ（全体）」→ **その場で選べる**（前は選んだ瞬間に閉じていました）
  [ ] `M` → 「表示 ▸」→「各種スイッチ…」→ **スイッチが開く**（前は開いて即閉じ）
  [ ] シェルにキーがある状態で `Shift+Enter` → シェルのメニューが開く
      （シェルでは `:` は文字なので、ここが唯一のコマンド行への入口です）


7. マウス
---------

  [ ] シェルを2つに分割（Shift+F8）→ **境界をドラッグして幅が変わる**
  [ ] ファイル行を**デスクトップやエクスプローラーにドラッグ**
      → ファイルそのものが落ちる（マークがあればマーク全部）
      ※ 端末版にはできないことです
  [ ] F3 で複数ファイルを開く（マークして F3）→ 題の `◂ ▸` で行き来


8. アーカイブ
-------------

  [ ] zip に Enter で入る → 中で `r` → 中のファイル名が変わる
  [ ] 中で `d` → 「アーカイブから削除」と訊く → 消える
      ※ zip だけです。tar は「まだ」と言います


9. ◆ サーバ（SFTP）── **一度も通していません**
------------------------------------------------

  ここが今回いちばん危ないところです。**壊れていても驚かないでください。**

  [ ] ◆ `:sftp` か `Shift+S` でサーバをペインに開く
  [ ] ◆ 大きめのファイル（数十 MB）を `c` で転送
      → **進捗バーが動き、バイト数とファイル名が出る**
        （これまでは「アップロード中…」と一度言って無言でした）
  [ ] ◆ サーバのファイルに `:chmod 644`
      → 「1 件を 644 にしました」と出て、一覧の権限が変わる
  [ ] ◆ 両方のペインをサーバにして `c`
      → 「この機械を経由します」と訊いてから転送される
        （サーバ間 SFTP は存在しないので、落として上げます）
  [ ] ◆ メニュー `M` →「転送 ▸」→「アップロード → サーバ」
      → ホストを選ぶと**反対のペイン**がそのサーバになり、
        「送り先まで移動して c」と出る

  ※ ◆ の途中で一時ファイルが残っていないかも見てください。
    経由用は %TEMP%\cian-relay に作り、成否にかかわらず消しています。


10. 最後に
----------

  [ ] `node gui\drive.js` は Windows では試さなくて構いません
      （画面と Electron が要るもので、こちらで回しています）
  [ ] ひととおり触ったあと、`:queue` に何も残っていないこと
  [ ] 窓を閉じて開き直し、配色・文字の大きさ・分割の比が戻ること


分かっている穴
--------------

- **AI の会話窓**はまだ1問1答です（履歴・停止・画像貼付なし）
- ビューアの**アウトライン列**は常設ではありません（`Ctrl+Shift+O` の一覧）
- **tar への書き戻し**はできません（zip だけ）
- md プレビューの**相対リンク**は開きません
- 対ディスクの**差分ガター**はありません
