cian（窓版）— macOS

これは cian の窓版です。Electron の front end と、その相手をするエンジン
（cian-server）が入っています。

■ 動かす

  Node.js と Electron が要ります（front end は JavaScript なので、
  コンパイラは要りません）。

    npm install
    npm start

  Electron を入れたくない場合は、この zip の中で

    npx electron .

  でも動きます。

■ 開かない・止められたとき

  ダウンロードしたものには macOS が「隔離」の印を付けます。
  cian は公証（notarize）していないので、次のどちらかが要ります。

    xattr -dr com.apple.quarantine .

  あるいは、システム設定 → プライバシーとセキュリティ → 「このまま開く」。

■ cian モード（ノート）

  init.lua に置き場所を書きます。examples/init.lua に見本があります。

    cian.notes{
      { name = "ノート", path = os.getenv("HOME") .. "/Documents/cian" },
    }

  窓の中で `:notes` と打つと、その置き場所へ飛びます。
  一覧はタイトルと二行目とタグになり、★ はお気に入りです。
  ノートの上で F3、その中で Ctrl+E がプレビューです。

  iPhone 版と同じフォルダを指せば、両方から同じノートを触れます
  （iCloud Drive・Google Drive・Dropbox のどれでも構いません）。

■ エンジンだけ入れ替えたいとき

  cian-server（このフォルダの中）を置き換えてください。
  front end は隣にあるものを先に探します。
