# cian

[English](README.md) · **日本語**

**C**omfortable **I**nterface for **A**gile File e**X**plorer **N**avigation —
[AFXW（あふｗ）](https://akt.d.dooo.jp/akt_afxw.htm)に着想を得た、モダンな2ペイン型ターミナルファイラーです。

任意のターミナルで動作します（WezTerm の `default_prog` として使う想定）。
クロスプラットフォーム対応：macOS / Windows / Linux。

## ステータス

開発初期ですが、実用に足る段階です。実装済み：2ペインのナビゲーション、
マーク／ビジュアル選択、進捗バー付きのファイル操作（コピー／移動／削除／
リネーム／作成）、インクリメンタルフィルタ、履歴、ショートカット、ペイン内
検索と再帰検索／grep、ソート、ファイル・ディレクトリ差分、テキスト／16進／zip
ビューア、チェックサムと属性、クリップボード連携、タブ・分割対応の組み込み
PTYシェルパネル、組み込みSFTP/SCP転送、Lua設定、完全に再割り当て可能な
キーマップ、そしてマウス操作対応のUI（クリック可能なダイアログを含む）。

## ヘルプ

cian内で **`?`**（または `Ctrl+.`、`:man`、**右クリック → Key manual**）を押すと
全キー一覧が出ます。これは現在のキーマップから生成されるので、`init.lua` で
割り当てたキーもそのまま載ります。シェルからは `cian -man` で同じものが、
`cian -h` でコマンドラインの使い方が表示されます。

マニュアルは**既定で日本語**です。`cian.set_option("lang", "en")` で英語に
切り替えられます。

## マウス

ほぼすべての操作をマウスで行えます。

**←** と **→** は2つのファイルペイン間のフォーカス移動です（2ペイン構成で
真っ先に使いたくなる操作）。`l` / `Enter` でディレクトリに入り、`-` /
`Backspace` で親に戻るのは従来どおり。**ダブルクリック**はエントリを実行します：
ディレクトリなら中に入り、ファイルならOS標準のプログラム（または `init.lua` の
`on_open` ハンドラ）で開きます。

任意の境界線をドラッグすると、その分割の比率を変えられます — 2つのファイル
ペイン、ファイル／シェルの仕切り、シェルパネル内のすべての分割が対象です。
どちら側も親の15%未満には縮められません。

エントリを反対側のペインにドラッグするとそこへコピー、Shift+ドラッグで移動
になります — いつもの確認が入るので、マウスの滑りで壊れることはありません。
シェルパネルにドロップした場合はプロンプトにパスを入力します。コンソール
アプリがターミナルへのファイルドラッグに一番近づける形です。

cianは **システムの** ドラッグ＆ドロップには参加できません：コンソールアプリ
にはドラッグ元／先になれるウィンドウがないため、Explorerとの間のドラッグは
できませんし、今後も対応しません。ターミナルのウィンドウにファイルをドロップ
するとパスが貼り付けられますが、それはターミナルの動作でありcianのものでは
ありません。

**ダイアログやピッカーもクリックできます。** 確認ダイアログには実際に
`[ Yes ]` / `[ No ]`（および `[ Overwrite ]` / `[ Rename ]`）ボタンが出ます。
一覧系 — ソート／文字コードのピッカー、SSHホスト／ユーザ、検索結果、コピー先、
履歴、ショートカット、ディレクトリ比較、書庫の中身 — はどれも行をクリックで
選択・確定でき、マウスホイールで開いているポップアップをスクロールできます。
キーボードショートカットも従来どおり動き、クリックはその代替という位置づけです。

`:copyto` と `:moveto`（メニューの **Copy to…**）は、選択物を反対ペイン以外の
場所へ送ります。最近使った送り先を候補に出します — 反対ペイン以外の送り先は
だいたい決まった数か所で、そのたびに打ち直すのが面倒だからです。ピッカー内で
`n` を押すと新しいパスを入力できます。

ペインを右クリックするとコンテキストメニューが出ます：コピー、カット、
ペースト、反対ペインへコピー／移動、リネーム、削除、ペインごとの背景色、
キー一覧（後ろ2つはシェルのメニューにもあります）。

背景色は右クリックしたペインに適用されます — シェル内の1つの分割だけにも
適用でき、パネル全体ではありません。シェルではシェルが色を塗っていないセル
だけを薄く染めるので、`ls` の色やエディタのテーマはそのまま出ます。コピーと
カットはナビゲート中も保持されるファイルクリップボードを満たすので、ここで
コピーして別の場所へ移動し、そこで貼り付ける、という流れが可能です。

**ペースト**は、cian自身のクリップボードに中身があればそれを、なければ
**システム**クリップボードを使います — ExplorerやFinderでコピーしたファイルが
フォーカス中のペインに貼り付きます。どちらを使ったかはステータス行に出ます。
`:paste` でも同じことができます。実在するパスでないクリップボード項目は
無視されます（プラットフォームの問い合わせはプレーンテキストとして返るため）。

`p` と `Shift+P` は逆方向で、パスやファイル参照をシステムクリップボードに
置きます。背景色はセッション限りです。

## アニメーション

分割・最大化（`F12`）・ペインを閉じる操作は150msでアニメーションします。PTYは
遷移が終わった時点で一度だけリサイズされるので、途中でシェルが再描画で崩れる
ことはありません。何かキーを押せば遷移は即座に完了します — 入力が遅延させ
られることはありません。調整・無効化：

```lua
cian.set_option("animation_ms", 250)   -- 遅く
cian.set_option("animation_ms", 0)     -- 無効
```

## ファイルシステムへの追従

他のもの — ビルド、ダウンロード、同期 — が作ったファイルは以前は決して
表示されませんでした：cianは自分の操作後にしか再読み込みしなかったからです。
今は各ペインのディレクトリを約1秒ごとに確認し、変化があれば読み直すので、
出現・消滅するエントリが自動的に反映されます。実測：外部で作られたファイルは
1秒以内に表示されます。

確認はディレクトリの `stat` 1回で、読み直しではないので、大きな一覧でも
コストはゼロです。そのため、エントリの増減を伴わないファイル**内容**の変化は
検知されません。`Ctrl+R`（または `F5`）で完全な再読み込みを強制できます。

## ファイル操作

コピー・移動・削除はワーカースレッドで進捗バー付きに実行されます：どこまで
進んだか、何ファイルか、何バイトか、どれくらい経過したか。**Esc** で中止
できます。以前はこれらがその場で動いていて — 700MBのファイルをコピーすると
UI全体が14秒間フリーズし、画面には理由も出ませんでした。

ファイルはチャンク単位でコピーされるので、大きなファイルの**途中**でもバーが
進み、中止は次のファイル境界を待たず一瞬で効きます。中止されたコピーは
書きかけの送り先を削除し、完成品に見えるものを残しません。移動はまずリネームを
試み（同一ボリューム内なら瞬時）、ボリューム跨ぎのときだけコピー＆削除に
フォールバックします。

### 送り先に管理者権限が必要なとき（Windows）

保護されたディレクトリ（`C:\Program Files`、`C:\Windows`）への書き込みは、
通常のプロセスでは「アクセスが拒否されました」で失敗し、cianが何をしても
ACLは越えられません。コピーや移動がこのエラーに当たると、cianはその旨を
はっきり伝え、Windowsでは **管理者として再試行** を提案します：UACプロンプトが
出て、転送が昇格して実行されます（ツリーはrobocopy、単一ファイルはCopy-Item）。
昇格コピーは別プロセスで動くため、アプリ内の進捗バーはありません — cianは
完了を待って結果を報告します（「as administrator」）。より簡単な代替策は、
cian自体を管理者として起動することで、以降はどの送り先にも書き込めます。
他のプラットフォームでは、通知が原因を明示し、書き込める場所を提案します。

## 削除

`d` は項目をOSのゴミ箱（FinderのゴミばこやWindowsのごみ箱）に移すので、
間違えても復元できます。確認ポップアップでは `a` で完全削除も選べます。

## ファイルとディレクトリの比較

`=`（または `:diff`）は左ペインのファイルと右ペインのファイルを左右に並べて
比較し、差のある行をハイライトします。`n` / `N` で変更点を行き来し、`f` で
同一部分を畳めます。

2つのペインを2つの**ディレクトリ**に向けて `=` を押すと、代わりに再帰的に
比較し、差のあるパスをすべて一覧します — 片方だけにある、もう片方に無い、
両方にあるが一致しない、を判別します。ファイルはサイズとタイムスタンプだけ
でなく**バイト単位**で比較され、ワーカースレッドで進捗バーとEsc付きで走るので、
「同一」という判定が本当に同一を意味します。結果でEnterを押すと両ペインが
そのパスに移動します。

## ファイル転送（SFTP / SCP）

SSHホストを設定しておくと（下記参照）、右クリックメニューに **Upload →
server** と **Download ← server** が増えます。ホストとユーザを選び、リモートの
ディレクトリ（アップロード）またはファイル（ダウンロード）を入力すると、
いつものワーカースレッドで進捗バーとEsc付きで転送します。

外部の `scp` バイナリを使わないピュアRust実装で、1回の認証済み接続上で
プロトコルを自動選択します：まず **SFTP**（今どきの `scp` が使っているもの）、
サーバにSFTPサブシステムが無ければ古典的な **SCP** プロトコルにフォールバック
します（一部のアプライアンスやロックダウンされたsshd構成が該当）。どちらで
運んだかはステータス行に出ます（「via SFTP」／「via SCP」）。単一ファイルと
ディレクトリ全体に対応します。ホスト鍵は現状 known-hosts 検証なしで受理します
（既知のギャップとして明記）。

## SSH

`Shift+S`、`:ssh`、または **右クリック → SSH connect…** で2段階のピッカーが
開きます：ホストを選び、次にそのユーザを選びます。

シェルペインにフォーカスがあるときに使えるのは右クリックです：そこではキーが
シェルに直接届くので、`Shift+S` は単に `S` を打つだけになります。だから
SSHはシェルペインのメニューの先頭にあります。ホスト段では入力でフィルタ
できます。ユーザが1人だけのホストは即座に接続します。コマンドはシェルパネルに
入力されるので、あなた自身のシェル設定とエージェントが効き、セッション終了時に
タブはローカルのプロンプトに戻ります。

```lua
cian.ssh({
  users = { "root", "deploy", "app", "taketan" },   -- 全ホスト共通の候補
  hosts = {
    { name = "web1", host = "10.0.1.11" },
    { name = "db1",  host = "10.0.2.31", users = { "postgres", "root" } },
    { name = "bast", host = "203.0.113.9", port = 2222 },
  },
})
```

8ホスト×4ユーザなら、32個のエイリアスを覚える代わりにここは十数行で済みます
— 覚えるのはピッカーの仕事です。同じホスト一覧が上のSFTP/SCP転送でも使われます。

### パスワード

ログインにパスワードを持たせられます。sshがパスワードを求めたときにcianが
入力し（SFTP/SCPの認証にも使われます）：

```lua
users = {
  { name = "postgres", password = "..." },        -- このファイルに保存
  { name = "deploy", password_cmd = "pass srv/deploy" },  -- 資格情報ストアから
  "root",                                          -- 鍵認証；何も保存しない
}
```

sshはパスワードをstdinではなく制御端末から読むため、パイプで渡せません — が、
その端末はcianが所有しているので、プロンプトが出た時点でPTYに書き込みます。
これはTeraTermの `.ttl` マクロや、その前身のexpect(1)がやっていることです。
cianは闇雲に送らずプロンプトを待つので、鍵認証のホストには何も届かず、試行は
20秒で失効します。ホスト鍵の確認は自動応答しません。

パスワードはログに残らず（`CIAN_LOG` 下でも）、ステータスバーにも出ず、
デバッグ出力からも伏せられます。

**トレードオフを理解してください。** `password` は平文の秘密を、バックアップ
され、マシン間でコピーされ、その中身に見合わない気軽さで共有されるファイルに
置きます。Unixでは、そのファイルが他人から読める場合、cianは起動時に警告します。
`password_cmd` は資格情報マネージャから値を取ることで、何も保存しないで済ませ
ます。鍵認証はそもそもこの問題を回避し、たいてい資格情報リストを維持するより
セットアップが楽です。

## 中身をのぞく

**`F3`** は「ここに何が入っているか」をcianを離れず答えます。テキストファイル
なら行番号付きのスクロール可能なビューアを、バイナリなら16進ダンプを開きます
（コンパイル済みファイルをテキストで見せても、一画面分の文字化けで何も
分からないからです）。読み込むのは先頭4MBだけなので、巨大なログでも一瞬で
開きます。ビューア内ではドラッグで選択、`c` で選択範囲をコピーでき、
`Shift+Enter` で文字コード（UTF-8 / Shift_JIS / UTF-16）を切り替えられます
（誤ったコードで読まれたとき用）。

**zip**（`.jar`、`.whl`、`.epub` も）なら、代わりに中身を展開後のサイズ付きで
一覧します。`Enter` でハイライト中の1つを反対ペインに展開、`a` で全部展開
します — ワーカースレッドで、いつもの進捗バーとEsc付きです。

メンバのパスは書き出す前に検査されます：書庫は `../../etc/passwd` や絶対パスを
名乗ることができ、素朴な展開器はそれに従ってしまいます。そうしたものは個別に
拒否し、書庫の残りはちゃんと取り出します。

対応は zip のみです。追加ソフト無しでWindowsが読み書きできる形式であり、
半分の形式で失敗するのに「書庫を開ける」と謳うのは、1つに絞ってはっきり
させるより悪いからです。

## 検索

`f` は現在の一覧内のマッチを行き来します。**`Shift+F`** はペインのディレクトリ
以下のツリー全体を、ワーカースレッドで検索します — 結果は探索の完了を待たず
見つかった順に現れ、`Esc` で中止、結果でEnterを押すとそのディレクトリに
カーソルを合わせて移動します。

**`Ctrl+F`** は代わりにファイルの**中身**をgrepし、マッチした各行を行番号付きで
一覧します。バイナリファイルはスキップされ（コンパイル済みオブジェクト内の
マッチは読めず何も分からないため）、8MBを超えるファイルもスキップされるので、
紛れ込んだDBダンプで検索が止まることはありません。

探索は幅優先なので、浅いマッチ — たいてい欲しいもの — が先に届き、途中で
やめた検索でも役立つ結果は出ています。隠しディレクトリはスキップされ、
シンボリックリンクのディレクトリは辿りません（ツリーを遡るリンクはループに
なるため）。検索は5000ヒットで打ち切ります。

## 属性・チェックサム・ドットファイル

`:attr` は選択物の権限と所有者を表示します。`:chmod 644` と `:readonly on|off`
で変更します。`:hash` は選択ファイルをチェックサムします — `:hash md5` や
`:hash sha256` — 他の長い操作と同じ進捗バーとEscを備えたワーカースレッドで
実行します（チェックサムする価値があるのは大きいファイルだからです）。

`:hidden` はフォーカス中のペインでドットファイルの表示を切り替えます。3つとも
右クリックメニューにもあります。ドットファイルは既定で表示されます（cianが
昔からそうしてきた挙動）。`cian.set_option("show_hidden", false)` で変えられます。

`:chmod` は8進数のみです。`u+x` のようなシンボリック表記はそれ自体が小さな
言語で、中途半端に実装するのは断るより悪いからです。Windowsにはモードビットが
そもそも無いので、`:chmod` は拒否して `:readonly` を案内します。

## パスへ移動

`z`（または `:cd`）は現在のディレクトリを初期値にしてパスを尋ねます。
ディレクトリなら中に入り、ファイルなら `Enter` と同じ方法で開きます（`init.lua`
の `on_open` ハンドラ含む）。`~`、`$VAR`、`${VAR}`、`%VAR%` は展開され、前後を
囲む引用符の対は取り除かれます — シェルやExplorerのアドレスバーからコピーした
パスをそのまま貼り付けられます。

## キーボードからのコンテキストメニュー

`Shift+Enter` は右マウスボタンと同じメニューを、ハイライト中のエントリの隣に
開きます。Shift+Enterを素のEnterと区別できるターミナルが必要です：Windows
コンソールは区別でき、Unixでは kitty キーボードプロトコル（WezTerm、kitty、
foot）が要ります。`:menu` はどこでも動きます。

## 選択

`v` でビジュアル選択を開始し、`Enter` でマークします。ビジュアルモード内では
`a` で一覧全体を選択、`gg` / `G` で先頭・末尾まで伸ばせます — なので `v a` でも
`gg v G` でも全選択できます。

テキスト欄（リネーム、新規ファイル、ショートカットの名前と対象）では
**Ctrl+V** で貼り付け、**Ctrl+U** でクリアできます。新しいショートカットの
対象はカーソル下のエントリで初期化されます（たいていそれをブックマークする
からです）。

## ソート

`,` でソートピッカーが開きます：名前・サイズ・日付・拡張子。`n`/`s`/`d`/`e` が
直接のショートカットです。すでに有効なキーを選ぶと、列ヘッダのように昇順・
降順を反転します。ディレクトリは常に先頭に留まります — サイズ順でフォルダが
一覧に散らばると、ペインがずっと辿りにくくなるからです。順序はペインごとで、
ステータスバーに表示されます（`size ▼`）。

## キーヒント

ステータス行の上のバーが、今使えるキーを一覧し、モードに応じて変わります。
`cian.set_option("key_hints", false)` で消せます。ウィンドウが狭いときは
自動的に引っ込みます。

## フィルタ

`/` は入力に応じて一覧を絞ります（大小無視の部分一致）。**Enter** でフィルタを
適用したままにでき、マッチだけをマークして操作できます。**Esc** でクリア
します。ステータスバーには有効なフィルタと、ディレクトリのエントリのうち
いくつがマッチするかが出るので、絞られたペインが満杯のペインに見えることは
ありません。ディレクトリを変えると必ずフィルタはクリアされます。

## キーの再割り当て

すべてのファイルペイン操作には名前があり、`init.lua` でキーに割り当てられます。
ユーザの割り当ては組み込みキーより先に参照されるので、キーを割り当てると
別名を足すだけでなくその既定を**置き換え**ます。`"none"` はキーを完全に無効化
します：

```lua
cian.set_keymap("x", "delete")   -- 追加：x でも削除できる
cian.set_keymap("d", "rename")   -- 変更：d は削除ではなくリネーム
cian.set_keymap("d", "none")     -- 無効化：d は何もしない
```

[`examples/init.lua`](examples/init.lua) は、すべての既定割り当てを「それを
再現する `set_keymap` 行」の形で列挙しているので、コメントを外して編集すれば
どれでも移動・無効化できます。アクション名の一覧も載っています。構造キー
（矢印、Enter、Backspace、Tab、Fキー、Ctrl-/Shift- の組み合わせ）は組み込みで、
ここでの再割り当て対象外です。

## アーキテクチャ

Cargoワークスペースで、6つのクレートに分かれています：

| クレート | 役割 |
|---|---|
| `cian-core` | 純粋なドメインロジック：ファイル操作、マーク、履歴、ソート、フィルタ、検索、差分、昇格 |
| `cian-tui`  | 描画と入力（ratatui + crossterm）、レイアウト、ポップアップ、マウス |
| `cian-pty`  | 組み込みシェルペイン（portable-pty + vt100 + tui-term） |
| `cian-scp`  | 組み込みSFTP/SCPファイル転送（ピュアRustのrussh、C依存なし） |
| `cian-lua`  | Lua設定ホスト（mlua）：キーマップ、テーマ、ext-open DSL |
| `cian-bin`  | エントリポイント — `cian` バイナリを生成 |

## 設定

cianは `~/.config/cian/init.lua` を読みます（ディレクトリは `$CIAN_CONFIG_DIR`
で上書き可能）。設定はLuaで書き、グローバルの `cian` テーブル上のWezTerm風の
小さなAPIを使います：

```lua
cian.set_theme({ accent = "#00d7d7", mark_fg = "yellow" })
cian.set_option("clipboard_on_copy", false)
cian.set_keymap("x", "delete")           -- キーを割り当てると既定を置き換える；"none" で無効化
cian.on_open("md", function(path)        -- 拡張子ディスパッチで実行
  cian.spawn({ "open", "-a", "Typora", path })
end)
```

このファイルは任意です — 無ければcianは既定で動きます。構文エラーや実行時
エラーは起動時の通知に出て、適用できなかった分は既定にフォールバックするので、
壊れた設定が起動を止めることはありません。

`:reload` で再起動せずに `init.lua` を再読込できます — キーマップ、オプション、
SSHホスト、openハンドラは即座に反映されます。カラーテーマと枠のスタイルは
起動時に一度だけ適用されるため、それらの変更は再起動が必要です（`:reload` は
その旨を伝えます）。

### Windowsのパスは `[[...]]` で

Luaではバックスラッシュがエスケープシーケンスの始まりなので、パスを `"..."` に
貼ると構文エラーになり — しかも設定ファイル**全体**を巻き込んで落とすため、
既定のシェルの上で「なぜ設定が効かないのか」と首をかしげることになります：

```lua
-- 悪い例：\W は有効なエスケープでなく、これはファイル全体を殺す
cian.set_option("shell", "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe")

-- 良い例：ロングブラケット内ではバックスラッシュは文字どおり
cian.set_option("shell", [[C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe]])

-- これもOK：素の名前はPATHから探される
cian.set_option("shell", "powershell.exe")
```

cianは無効なエスケープを見つけると、このヒントを起動時の通知に追加します。

完全にコメント付きのテンプレートと、割り当て可能なアクションの全一覧は
[`examples/init.lua`](examples/init.lua) を参照してください。

## シェルパネル

下部パネルはあなたの `$SHELL` を走らせる本物のPTYで、最初にフォーカスした
ときに起動します。`Shift+J`（ファイルペインから）、マウスクリック、`:shell`
でフォーカスします。シェルにフォーカスがある間、キーはそこへ直接届きます。
**Esc** でファイルに戻ります。Escはフルスクリーンのプログラム（vim、less、
htop、…）には通されるので、それらは動き続けます — Escで抜けるのは通常の
プロンプトにいるときだけです。

**テキストの選択：** cianがマウスを所有しているため、ターミナル自身の選択は
シェルに届きません。代わりに、シェルペイン内を素のドラッグで選択でき、離すと
選択範囲がクリップボードにコピーされます — 修飾キーは不要です。

シェルペインを**右クリック**するとメニューが出ます：SSH接続、ペースト、
**セッションログ**の開始／停止（伏字処理された記録をファイルに書き出す）、
SFTP/SCPのアップロード／ダウンロード、そしてUTF-8以外のコードページを話す
シェル向けの**文字コード**ピッカー（UTF-8 / Shift_JIS / UTF-16LE / UTF-16BE）。

シェルタブはファンクションキーで操作します（Ctrl系のショートカットは、一部の
環境がCtrl修飾をアプリに届く前に飲み込むため信頼できません）：

| キー | 動作 |
|---|---|
| `F1`–`F8` | シェルタブ 1–8 に切り替え |
| `F9` | 新しいシェルタブ |
| `F10` | シェルタブを閉じる |
| `Shift+F1` / `Shift+F2` | 次／前の分割ペインにフォーカス |
| `Shift+F8` | **左右分割** — アクティブなペインを左右2つに割る |
| `Shift+F9` | **上下分割** — アクティブなペインを上下2つに割る |
| `Shift+F10` | アクティブな分割ペインを閉じる（確認あり） |
| `F12` | フォーカス中の面をウィンドウいっぱいにズーム（トグル） |
| `Shift+F12` | アクティブな分割ペインだけをズーム（トグル） |

分割は入れ子になります：分割は常にアクティブなペインを割るので、任意の
レイアウトを組めます（例：左に1ペイン、右に上下2ペイン）。これらのキーは
通常のプロンプトでのみ有効で、フルスクリーンアプリ（vim、htop、…）には
ファンクションキーがそのまま渡されます。

ファイルペインは並行するコントロールを使います：`Shift+F1` / `Shift+F2` で
次／前のタブに切り替え、`Shift+F10` でアクティブなタブを閉じます（確認あり）。

## ビルド

```sh
cargo build --release
./target/release/cian
```

## どのビルドが動いている？

```sh
cian --version     # cian 0.1.0 (7f92bae)
```

コミットはビルド時に埋め込まれます。機能が無いように見えるときは、まず確認する
価値があります：PATHに残った古い `cian.exe` は、バグとまったく同じに見えます。

## 枠の角

丸い角（`╭╮╯╰`、U+256D–U+2570）は、いくつかの標準的なコンソールフォント —
ConsolasやLucida Consoleなど — に無い一方で、直線の `─│` はほぼすべてに
あります。するとWindowsは角だけを別の書体にフォントリンクし、そのメトリクスが
違うため、辺は揃っているのに各角が数ピクセルずれて見えます。

そこでcianはレガシーなWindowsコンソールでは四角い角、それ以外では丸い角を
使います。どちらかに強制するには：

```lua
cian.set_option("borders", "rounded")   -- または "plain"
```

## 単体で起動する

cianは起動先のコンソールの見た目は変えられません。フォントと色はホスト
ターミナルのものです。`cian.exe` をダブルクリックしたり `cmd` から実行すると
レガシーなWindowsコンソールに着地し、そこではNerd Fontのアイコンが豆腐に
なります。それを検知すると起動時に一度その旨を伝えます。

意図した見た目にするには、Windows TerminalかWezTermから起動してください：

```powershell
wt cian
```

## トラブルシューティング

cianの挙動がおかしいときは、`CIAN_LOG` を設定して診断情報を取ってください —
シェルの起動、パニック、PTYのエラーがそこに追記されます。変数が未設定（既定）の
ときはログ出力は何もしません：

```sh
CIAN_LOG=/tmp/cian.log cian
```

パニック時はアンワインドする前にターミナルを復元するので、rawモードのまま
`reset` が必要な状態に取り残されることはないはずです。

## Windowsへのインストール（オフライン）

cianは自己完結した単一の `cian.exe` にコンパイルされます — ランタイム不要、
DLL不要、実行時のネットワークアクセス不要です。Windows開発マシン無しで
Windows x64ビルドを得るには、同梱のGitHub Actionsワークフローを使います。
本物のWindowsランナー上でビルドし、持ち運べるzipにまとめます：

1. ビルドを起動 — タグをpushする（`git tag v0.1.0 && git push --tags`）か、
   リポジトリの **Actions** タブ → **release** → **Run workflow**。
2. そのrunのアーティファクトから `cian-windows-x64.zip` をダウンロード
   （タグ付きビルドはGitHub Releaseにも添付されます）。
3. zipをオフラインのマシンに持ち込んで展開します。あとは `cian.exe` を
   そのまま実行するか、`install.ps1` を実行して `cian` をPATHに通します：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

   既定では現在のユーザ向け（管理者不要）に `%LOCALAPPDATA%\Programs\cian` へ
   インストールします。全ユーザ向けにProgram Filesへ入れるには、**昇格した**
   PowerShellで送り先を渡して実行します：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1 -Dest "C:\Program Files\cian" -AllUsers
   ```

   インストーラはexeのブロックを解除し（ターミナル起動が「アクセス拒否」に
   ならないように）、フォルダをPATHに追加します。新しいターミナルを開いて
   `cian` と入力してください。ファイル種別アイコンにはNerd Fontのターミナル
   （Windows Terminal / WezTerm）を使ってください。
