# ほかのアプリから ambər で開く（依頼 668）

ambər は Markdown 以外のテキストも直せます。`.py` も `.log` も `.csv` も
`.json` も、**読めるものなら開きます**。

- **Markdown（`.md` / `.markdown`）だけが表示画面を持ちます。**
- **ほかはコード画面で開き、表示画面には切り替わりません。** 表示画面で開くと
  `# ` が見出しに、`* ` が箇条書きに組み直され、保存で ambər の書き方に
  寄ります ── `.py` なら、**動かないコードが出来ます。**
- 保存は**読んだときの文字コード・BOM・改行のまま**です。会社の Shift_JIS・
  CRLF の `.txt` も、一行も差分が出ません。
- **ambər に取り込めるのは Markdown だけ**です。ほかのファイルは直すだけで、
  ノートの一覧には入りません。

開けないもの:

| | |
|---|---|
| フォルダ | 断ります |
| 32 MB より大きいファイル | 断ります |
| binary | 先頭 8000 バイトに `00` があれば断ります |
| UTF-8 でも Shift_JIS でもないもの | 断ります |

## 開き方

### どの環境でも ── 窓にドラッグ＆ドロップ

ファイルを ambər の窓に放り込みます。**いちばん速い道**です。

保存ディレクトリの中のファイルなら、いつものノートとして開きます。外のもの
なら、単発で開きます（帯に「元のファイルを直しています」と出ます）。

### macOS ── 「このアプリケーションで開く」

Finder でファイルを右押し →「このアプリケーションで開く」→ ambər。

出てこないときは「その他…」から `ambər.app` を選び、**「常にこのアプリケー
ションで開く」には印を入れない**でください（既定を奪わない作りにしてあります）。

### Windows ── 「プログラムから開く」

**最初の一度だけ**、こう辿ります。

1. ファイルを右クリック →「プログラムから開く」→「別のプログラムを選択」
2. 一覧に ambər が無ければ「**この PC で別のアプリを探す**」
3. 展開したフォルダの `amber.exe` を選ぶ
4. **「常にこのアプリを使って開く」には印を入れない**

二度目からは、「プログラムから開く」の一覧に ambər が並びます。

**レジストリをいじる道具は同梱していません。** 関連付けを登録する `.reg` や
`.cmd` は、会社の端末では走らせられない人がいるためです（本人が決めた・
2026-10-26）。上の手順はマウス操作だけで済みます。
