# OneNote を ambər へ写す

OneNote のノートブック / セクショングループ / セクション / ページを、**その形の
まま**フォルダと `.md` にして書き出す。往きだけ ── ambər で直したものは
OneNote へは戻らない。

## ambər の中から（依頼 621）

**⚙ →「OneNote を取り込む」**（「インポート」のすぐ下）。Python もバッチも要らない。

1. **取り込むもの** ── ドキュメント・ダウンロード・デスクトップの直下にある
   `.onepkg` が新しい順に並ぶ。無ければ「ファイルを選ぶ…」（`.onepkg` / `.one`）か
   「フォルダを選ぶ…」（`.one` が入ったフォルダ。目次の `.onetoc2` があればその順）
2. **書き出し先**（初回だけ訊いて憶える）
   - **ドキュメント／OneNote**（おすすめ）── 新しい保存ディレクトリとして足す
   - いまの保存ディレクトリの中の「OneNote」フォルダ
   - フォルダを選ぶ…
   
   ⚙「保存ディレクトリの追加・変更・削除」から外すと、次にまた訊く
3. セクションごとに ✓ が付いていく。**ダイアログを閉じても裏で続く**（もう一度 ⚙ から
   開くと進み具合に戻る）

置かれる形:

```text
<書き出し先>/<ノートブック>/<セクショングループ>/…/<セクション>/<ページ>.md
                                                  /attachments/<ページ>-001.jpg
```

**パーサーは外部クレート**（[onenote_parser](https://github.com/msiemens/onenote.rs)・MPL-2.0）──
下の Python 版は公開仕様の `.one` しか読めないが、こちらは **SharePoint／OneDrive
から落とした形（`638DE92F…`）も読む**。

| | ambər の中から | Python 版（下） |
|---|---|---|
| 太字・斜体・取り消し・色・リンク・見出し・点と番号の入れ子・表・画像 | ✓ | ✓ |
| 添付ファイル | **中身ごと** `attachments/` に置いてリンク | 名前だけ |
| タスク（`- [ ]`）・引用・コード | まだ | ✓ |
| サブページ | セクションのフォルダに並べる | 親ページ名のフォルダへ |
| 同じ題のページ | `-2` を付ける（**上書きしない** ── 二度取り込むと二枚になる） | 上書き |

**Python 版（`onenote2md.bat`）は、ambər の中からの取り込みが本人の端末で
通るまで残す。**

## Python 版（`onenote2md.bat`）

**押すのは一回。** `scripts\onenote2md.bat` をダブルクリックすると小さいダイアログが
出るので、取り込むものと出力先を選んで「取り込む」を押す。それだけ。

> **前は OneNote に直接繋いでいた**（COM）。本人の会社の端末ではどうやっても
> 繋がらず（登録も実体も取り次ぎ側も権限も bit も白く、Office のクイック修復でも
> 変わらなかった）、2026-09-16 にその方式ごと外した。いまは**書き出したファイルを
> 直に読む**ので、Office も pywin32 も 32 bit の Python も要らない。
> 経緯は [REQUESTS.withdrawn.ja.md](../REQUESTS.withdrawn.ja.md)。

## できること・できないこと

**できる**

| | |
|---|---|
| 階層 | ノートブック › セクショングループ › セクション がそのままフォルダ。サブページは親ページ名のフォルダへ |
| 中身 | 見出し・太字/斜体/取り消し線・箇条書き・番号・引用・コード・表・リンク・**画像** |
| 表 | OneNote 側で「見出しの行」にしてある行だけを見出しにする。無ければ空の見出しを置く ── 1 行目を見出しに使うと、**そのデータが一行、表から消える** |
| チェックボックス | OneNote の「タスク」タグ → `- [ ]` |
| 色 | `<span style="color:#rrggbb">` ── ambər の書き方。「自動」は色として出さない |
| 前書き | `title` / `created` / `onenote_path` ── ambər はこの `title` をタイトルとして読む |
| 画像の名前 | `attachments/<幹>-001.png`（**ハイフン**・ファイル名の本体は 60 文字まで）── ambər は「本体 + ハイフン」で自分の画像を見分ける（`note::attach`）。アンダースコアだと、ノートを改名・移動した日に画像が付いてこない |

**できない**

- **手書き（インク）**。`> [インク: 変換対象外]` と置くだけ。OneNote の XML に
  文字は入っていないので、こちらでは何もできない。
- **表のセル内の改行**。Markdown の表に改行を入れる書き方が無いので、空白で
  つなぐ。（`<br>` では ambər の画面に `<br>` という文字が出る ── 本文中の
  生の HTML はすべて文字として出す決まりなので。）
- **行頭の記号を逃がすこと**。OneNote で `# 会議` と書いた段落は、写した先で
  見出しになる（`- ` や `1. ` も同じ）。**ambər はバックスラッシュの逃がしを
  読まない** ── エスケープすると今度は `\` が文字として出る（2026-09-16 に実測:
  `\# 会議` は見出しにならないが `\#` のまま出る。`\*星*` に至っては
  逃がせず `\` と斜体が両方出る）。
  **デスクトップ版と iPhone で食い違ってはいない** ── 「表示」画面はどちらも core の
  `to_html` を通るので、同じものが出る。

  **2026-09-16、このままにすると本人が決めた。** 決め手はファイルパス ──
  いま `C:\Users\t502960\Documents\amber` も `\\server\share\資料` も、
  打ったとおりに出る（`\` を一つも食わない）。逃がしを読むようにすると
  CommonMark の決まりで `\\` が一組の逃がしになるので、**`\\server\share` が
  `\server\share` になる** ── 会社で毎日書く UNC パスが壊れる。
  本人の言葉:「特殊文字・意味のある記号の逃がしなら、そのままでよい」。
- **添付ファイルの中身**。`添付ファイル: 見積.xlsx` と名前だけ残す。
- **ページ上の自由な配置**。OneNote は箱をどこにでも置けるが Markdown は一列なので、
  **上から下・左から右**の順に潰す。
- **蛍光ペンと文字の大きさ**。ambər 側に書き方が無いので、落とすなら先に
  決めごとが要る。
- **パスワードをかけたセクション**。OneNote が書き出さないので、中身が無い。
- **往復**。ambər 側で直したページは、次に取り込んだときに上書きされる。
  **一方通行だと思って使う。**
- **自動で回すこと**。`.onepkg` を作るのは OneNote に手で押してもらうしかない
  （ここが自動にならない）。月に一回、押して取り込む。

## 要るもの

**Python だけ。** Office も pywin32 も要らない。ネットワークにも出ない。
mac でも Linux でも動く（`.one` はただのバイナリで、読むのはこちら側）。

Python が入っていなければ、python.org の Windows installer を持ち込んで入れる。
バッチが見つけられなければ、そう言って止まる。

## OneNote から書き出す（月に一回）

1. OneNote で **ファイル → エクスポート**
2. 左で**ノートブック**を選ぶ（セクション単位でもよい）
3. 形は **OneNote 単一ファイル パッケージ（`.onepkg`）**
4. 保存

> **まとめて出せるのは `.pdf` `.xps` `.onepkg` の三つだけ。** 押すのは一回で、
> 中に全セクションが入る。遅いので、出るまで待つ。

## 取り込む

`scripts\onenote2md.bat` を**ダブルクリック**。ダイアログが出る:

- **取り込むもの** ── `.onepkg` / `.one` / それが入ったフォルダ
- **出力先** ── 既定は `ドキュメント\OneNote`

**`.onepkg` をバッチに放り込んでもいい** ── そのときはダイアログを出さず、既定の
出力先へそのまま取り込む。

コマンドで打つなら:

```bat
py -3 scripts\onenote2md.py --out "%USERPROFILE%\Documents\OneNote" "…\まとめ.onepkg"
py -3 scripts\onenote2md.py --peek "…\書き出し"     … 形式を数えるだけ
```

**`.onepkg` の名前が、そのままノートブックのフォルダ名になる。** 何本あっても、
手でフォルダを分ける必要はない。

> **読めるのは公開仕様の `.one`**（`109ADD3F…`）。SharePoint に置かれている
> ものは `638DE92F…` という別ものだが、**書き出せば公開仕様で出てくる。**
> どちらかは `--peek` が数えて言う。

## うまく写らないとき ── まず `--peek`

```bat
py -3 scripts\onenote2md.py --peek "…\まとめ.onepkg"
```

入れ物の中を**そのまま**出す ── フォルダの数・ファイルの数・**圧縮の種類**と、
中に入っているセクションのパス（`400_打合せ/水曜日打合せ.one`）。
**名前や階層がおかしければ、ここで分かる。**

> **`.onepkg` は自分でほどく**（依頼 617）。CAB の頭も目録も中身も
> こちらで読むので、`expand` は呼ばない ── あれは**日本語の名前を壊す**し、
> 出したファイルを大きさで突き合わせるしかなくなる。
> 名前は**旗を見る前に UTF-8 を試す** ── OneNote は `_A_NAME_IS_UTF` を
> 立てずに UTF-8 で書いていて、それを cp932 で読むと
> 「数字はそのまま、漢字だけ読めない」という顔になる。
>
> ほどけるのは**無圧縮と MSZIP**。`--peek` が `LZX` や `Quantum` と言ったら、
> そのときだけ Windows の `expand` に回す（名前は目録から付け直す）。

## 写すものを選ぶ

全部でなくていいなら、2 つ。**照合するのは `ノートブック/グループ/セクション` のパス**で、
大文字小文字は問わない。

| | |
|---|---|
| `--only 仕事/議事録` | これだけ写す。部分一致・複数可（重ねれば足し合わせ） |
| `--skip 仕事/私的` | これだけ外す。**`--only` より強い** |

```bat
py -3 scripts\onenote2md.py --out ... --only "仕事/議事録" --only "私用/買い物" "…\まとめ.onepkg"
```

`--only 仕事` のようにノートブック名だけ書けば、その下ぜんぶ。
`--only 案件/A社` のようにグループから書けば、そのセクションだけ。

**何が入っているかを先に見るなら** `--dry-run` ── どこに何を書くかを並べるだけで、
一文字も書かない。

**ページ単位では選べない。** セクションまで。

## ambər が読める形

**正本は Rust のほう。** 画像の名前の付け方は `crates/amber-core/src/note.rs` の
`attach`（`format!("{}-{stamp}.{ext}", file_stem(&stem))`）と `file_stem`。
ここはその**写し**（`amber_stem`）なので、走査が**同じ答えになること**と
**正本にその規則がまだあること**を両方見ている ── ずれると、ambər が
ノートを改名・移動した日に**画像だけが付いてこない。**

```
<保存ディレクトリ>/
  仕事/                      ← ノートブック
    議事録/                  ← セクション
      9月の定例.md
      attachments/
        9月の定例-001.png    ← <幹>-NNN.<ext>
      9月の定例/             ← サブページ
        補足.md
```

```markdown
---
title: "9月の定例"
created: 2026-09-02        ← この端末のローカル日付（UTC を切り落としたものではない）
modified: 2026-09-10T02:00:00.000Z
onenote_id: "{P1}"
onenote_path: "仕事 / 議事録"
---
# 9月の定例

# 決めたこと
ふつうの**太い**文字
- [ ] 宿題
![](attachments/9月の定例-001.png)
```

**説明は空のまま**（`![](…)`）── ambər が自分で貼るときもこの形で、
`image` と埋めると**その文字列が、サイズ指定（`![猫 w:200]`）を書く場所を占めてしまう。**

## ambər に読ませる

⚙「保存ディレクトリの追加・変更・削除」で出力先を足す。同期の設定は要らない
（ただのフォルダなので）。前書きの `title` がタイトルになり、フォルダがそのまま索引に
なる。

### 何が Markdown に落ちるか

| OneNote | Markdown | 備考 |
|---|---|---|
| ページ名 | front matter の `title` と `# 見出し` | 同じ名前は `名前 (2).md` にずらす |
| ページの階層（サブページ） | フォルダ | `PageLevel` を見る |
| セクショングループ | フォルダ | `400_打合せ/水曜日打合せ/…` がそのまま残る。パスは CAB の目次から取る（依頼 617） |
| 見出しの段落書式 | `#` 〜 `######` | `ParagraphStyle` の名前から |
| 太字・斜体・取り消し線 | `**…**` `*…*` `~~…~~` | 両方なら `***…***`。**旗は `ParagraphStyle` が持っている**（依頼 608 まで、本文から読んでいて一度も落ちていなかった） |
| 文字の色 | `<span style="color:#rrggbb">…</span>` | ambər の書き方。**「自動」は色として出さない**（出すと全部の行が span に包まれる） |
| リンク | `[テキスト](url)` | `WzHyperlinkUrl` から。適用順は**リンクがいちばん内側・色がいちばん外側** |
| 箇条書き・番号 | `- ` `1. ` | 入れ子はインデント（6 段まで） |
| 表 | パイプの表 | **見出しの行は空**（下記） |
| 画像 | `![](attachments/<幹>-001.png)` | ambər の決まりどおり（依頼 593） |
| 作成日時 | front matter の `created` | 1980-01-01 からの秒 |

**改訂は重ねて読む。** `.one` は履歴を丸ごと持っていて、**最後の改訂は
「変えたところ」しか持たないことがある** ── 直していない本文も、ページ
そのもののレコード（`Page`）も前の改訂に置きっぱなしになる。最後だけを見ると
**題だけのノート**や、**ページまるごとの取りこぼし**になるので、
本文が空のときは **OID で重ねて**拾い直す（新しい版が、古い版の居た場所に
座る ── 同じ題が何度も出ないのはこのため・依頼 617）。

**表の見出しの行は、わざと空にしてある。** Markdown の表は見出しの行が
要るが、OneNote が「1 行目は見出し」と決めているかは `.one` から素直に
引けない。**1 行目を見出しに使うと、それが見出しかどうか分からないまま
データが一行消える** ── 消えるより、空の行が一本増えるほうがいい
（依頼 578 で決めた形）。

**セル内の改行は空白でつなぐ。** Markdown の表に改行は入らず、`<br>` は
ambər の画面に文字として出る。

**まだ落ちないもの**: 埋め込みファイルの中身、手書き、**蛍光ペン**、**文字の
大きさ**。後ろの二つは ambər 側に書き方が無いので、落とすなら先に決めごとが要る。

## mac では

**mac でも動く。** 読むのは書き出されたファイルなので、OneNote も Office も
要らない ── `.onepkg` を Mac へ持ってくれば、そのまま取り込める。

```bash
python3 scripts/onenote2md.py --out ~/Documents/OneNote ~/Downloads/まとめ.onepkg
```

書き出すところだけは Windows の OneNote で押してもらう（Mac 版の OneNote には
「ノートブックごと書き出す」が無い）。

## 直したときは

python3 scripts/onenote-test.py     # 走査（mac でも通る）
