# Windows で確かめる

**mac では一生出ない類が、ここにしか出ない。** amber はその型を何度も踏んで
いる（道の区切り・鍵盤の名前・画像の道・改行・時計の粗さ）ので、**そこから
順に**並べる。上の五つが本命で、そこまでで二十分ほど。

うまくいかなかったら、**押した順と、画面の写真**を送ってほしい。
「動かない」だけだと、どの版のどこで止まったのかが分からない。

まず ⚙ →「amb**ə**r について」で**版**を控える（`3.0.1` のはず）。

---

## 一. ノートが、ただの Markdown ファイルとして置かれているか ★本命

1. 起動したら、見本のノートが三枚入っている
2. エクスプローラーで **`ドキュメント\amber`** を開く
3. `ambər へようこそ.md` が、**その名前のまま**見えるか

> **見るのはここ。** 名前が `amb?r` や文字化けになっていないこと。
> zip の中の名前は確かめたが、**amber 自身が書くファイル名は初めて**。

---

## 二. 書いて、閉じて、開き直す ★本命

1. 左の列の「新しいノート」→ タイトルに **日本語**（例: `会議メモ`）
2. 何行か書く。**空行を挟んだ段落**を二つ以上
3. 別のノートに移ってから、戻ってくる ── 字はそのままか
4. エクスプローラーで `会議メモ.md` を**メモ帳**で開く

> **見るのはここ。** メモ帳で**行が繋がって一行に見えないか**。
> Windows の改行は `CRLF`、amber の中は `LF` で、繋ぎ目を間違えると
> こう出る。VS Code ではなく**メモ帳**で見てほしい（あちらは賢すぎて隠す）。

---

## 三. 日本語入力と鍵盤 ★本命

| やること | こうなってほしい |
|---|---|
| IME で変換中に **Enter** | 変換が確定するだけ。**行が増えない** |
| 見出しの行末で Enter | 次は**本文**の段落になる |
| 箇条書きの途中で Enter | 次も箇条書き。空のままもう一度で抜ける |
| 表のセルで Enter | **下のセル**へ。最後の行なら行が一つ増える |
| `Ctrl+S` ・ `Ctrl+Z` ・ `Ctrl+F` ・ `Ctrl+N` | 保存・取り消し・探す・新しいノート |

> **ここがいちばん怪しい。** JIS の鍵盤は変換キーの名前が
> `Zenkaku` にも `Process` にも `Unidentified` にもなる ── mac では
> 一生出ない。**一つでもおかしければ、そのキーと出来事を書いて送ってほしい。**

---

## 四. 画像 ★本命

1. どこかの画像をコピーして、ノートに **`Ctrl+V`**
2. 画像が**その場に出る**か
3. ノートを閉じて開き直しても、まだ出ているか
4. エクスプローラーで `ドキュメント\amber\attachments\` を見る

> **見るのはここ。** 依頼 380 で、**会社の Windows でだけ画像が読めなかった**
> ことがある（`C:\Users\…` を道として組み立てるところが壊れていた）。
> 直してあるが、**直ったところを本物の Windows で見たことがまだ無い。**

---

## 五. 直したタイトルが、古いまま出ないか ★本命

1. 左の列の**カレンダー**を開く。ノートに日付を書いていなければ、
   何もない月の表でよい
2. いったん閉じて、どれかのノートの**タイトルを一字だけ**直す
   （例: `会議メモ` → `会議メモい`。**長さを変えない**のがねらい）
3. すぐにカレンダーを開き直す

> **見るのはここ。** 新しいタイトルで出るか。古いままなら、それが依頼 552 だ。
> **Windows の更新時刻は約 15 ミリ秒でしか進まない**ので、同じ刻みのあいだに
> 同じ長さで書き替えると「変わっていない」と見える ── 直したばかりだが、
> **踏んだのは CI の中だけで、本物の Windows では見ていない。**

---

## 六. ネットが無いときの顔

1. 一覧の上の「**同期をはじめる**」を押す
2. カレンダーの「**グループを作る**」を押す

> **見るのはここ。** どちらも**読める言葉で断る**こと。
> 固まる・無言で何も起きない・英語のエラーが出る、はどれも駄目。
> 配布先はネットに出られない端末なので、**断り方が製品の一部**。

---

## 七. カレンダー

1. **日・週・月・並べて**を押して回る
2. ノートの前書きに `remind: 2026-09-20` と書いて、その日に出るか

> Windows には「この端末の予定表」が無い（あれは mac と iPhone の話）ので、
> **出るのはノートに書いた予定だけ**。予定表の一覧が空でも正しい。

---

## 八. タブ

1. 一覧のノートを**四本**続けて押す → **タブが四枚**並ぶ
2. タブを右押し →「このノート以外をすべて閉じる」
3. amber を閉じて、開き直す → **開いていたタブが戻る**

> 昨日まで「仮のタブ」で二枚しか出なかったところ。**全部憶える**に変えた
> ので、開き直したときに戻るかまで見てほしい。

---

## 九. 保存場所を変える

⚙ →「保存ディレクトリの追加・変更・削除」から、別のフォルダを足す。

**会社の共有フォルダ（`\\サーバー名\共有\…`）があれば、そこを試してほしい。**
道の頭が `\\` で始まるものは組み立て方が違う ── そこも mac には無い形だ。

---

## 十. 終わりに

一周したら、**動いたもの／動かなかったもの**をそのまま送ってほしい。
「ぜんぶ動いた」も立派な結果で、**Windows で一周した記録はまだ一度も無い。**
