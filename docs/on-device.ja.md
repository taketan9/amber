# 実機で確かめる

**シミュレータで通っても、実機では落ちる。** 逆もある。ここは「自分の手で
確かめたいとき、何をどう押すか」だけを書く。

---

## 入れる

```bash
./scripts/phone-install.sh          # つながっている実機ぜんぶに入れる
./scripts/phone-install.sh --list   # いま見えている実機を数えるだけ
./scripts/phone-install.sh 太郎     # 名前の一部で選んで、その一台だけ
```

ビルドして、インストールして、**いつ期限が切れるかまで言う**。

### 新しい端末を足すとき

**一度だけ、ケーブルでこの Mac につないで「信頼」を押してもらう**（その端末の
暗証番号が要る）。**持ち主自身に押してもらうこと** ── 人の端末なので、こちらで
代われないし、代わるべきでもない。つないだあと `--list` に出てくれば準備は済み。

### 七日で切れる

いまの署名は**無料の個人チーム**なので、入れたアプリは **7 日で起動しなくなる**。
切れたらこの道具をもう一度走らせる。

七日ごとに端末を集めて回るのが続かないなら、**Apple Developer Program（年 99
ドル）の TestFlight** にすると、ケーブルも Mac も要らず、招待のリンクから自分で
入れられて 90 日動く。家族に配って使ってもらうならそちらが本筋。**お金の話なので
本人が決める。**

## デスクトップ版（Mac）を確かめる

```bash
./gui/run.sh
```

**本人のアプリが動いているあいだは、2 つ目を起動しない** ── `amber.json`（開いて
いるノート・見方・テーマ）を取り合う。走らせる前に閉じること。

画面を撮って残したいときは:

```bash
cd gui && AMBER_SHOT=/tmp/a.png AMBER_DO='cmdCalendar()' \
  AMBER_DO_WAIT=1500 AMBER_SHOT_WAIT=3500 node_modules/.bin/electron .
```

`AMBER_DO` は**画面の関数をそのまま呼べる**ので、手で押さずに同じ場面を出せる。
**撮ると `amber.json` の「開いていたノート」が動く**ので、大事なときは先に
控えて、終わったら戻す。

## いま確かめたいこと（2026-09-13 時点）

### 一. グループカレンダーを作る

デスクトップ版なら**カレンダーのツールバーの「グループを作る」**、iPhone なら
**カレンダーの「予定を登録する」の隣**。押すと確認が出て、「作る」で 1 つできる。

見たいのは三つ。

1. **Google の許可の画面に、カレンダーの許可が出てくるか**（Drive のときと
   別の文言になるはず）
2. **作ったあと、端末のカレンダーアプリに降りてくるまで何分か** ── いまは
   「少し時間がかかることがあります」と曖昧に言っている。数秒なら言わなくて
   よいし、数分なら別の言い方が要る。**時計を見て測ってほしい**
3. **「グループへ招待」が開く画面**が、そのカレンダーの共有設定になっているか
   ── URL の形を**まだ確かめていない**（違っていれば設定の入口が開く）

要らなくなったら、Google カレンダーの画面からそのカレンダーを消せる。

### 二. 予定のメモ欄のタグ

タグは**メモ欄のいちばん最後の、タグだけの行**に置く。確かめるのは
「**人が書いた文章に触っていないか**」。

```bash
./target/mac/amber-cal ask     # 一度だけ、許可を貰う
```

そのあと、カレンダーアプリで予定を一本作り、メモに文章を書いて、最後の行に
`#太郎 #次郎` と置く。別の端末やアプリで開いて、**その行が残っているか**。
一度直して保存し直しても残るか。

## 踏んだことのある罠

- **シミュレータを実機だと思って見ていた**（2026-09-13）。`phone-install.sh`
  は実機にしか入れないので、パスを分けてある
- **識別子は二つある** ── `devicectl` が返すものと `xcodebuild` が受けるものは
  別物。取り違えると「その端末は見つかりません」で止まる
- **ビルドが通っても、壊れていることがある** ── Swift の `@MainActor` は
  直前の関数に付くので、あいだに新しい関数を挟むと**静かに付け替わる**
